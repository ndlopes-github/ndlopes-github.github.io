# Nuno David Lopes — research homepage

Static personal research page: a single `index.html`, one stylesheet, one script (`js/site.js`), and self-hosted animations in `media/`. It makes no third-party requests. Publications and the gallery are generated into marked blocks of `index.html` by `julia tools/pubs/build.jl` and `tools/gallery/build.sh`.

- **Preview:** open `index.html` in a browser.
- **Deploy (GitHub Pages):** push this directory to a repository named `ndlopes-github.github.io`. Pages serves it from the default branch root at https://ndlopes-github.github.io/.
- **Edit:** see `CLAUDE.md` for where content comes from and the conventions for adding publications.

The 2011 version of the page is preserved at [Arquivo.pt](https://arquivo.pt/wayback/20110707033620/http://cmaf.ptmat.fc.ul.pt/~ndl/).
